# LUNA Store

فروشگاه اینترنتی LUNA با رابط HTML/CSS/JavaScript، سرور Node.js/Express و پایگاه داده SQLite.

## پیش‌نیاز

- Node.js نسخه ۲۰ یا جدیدتر
- دسترسی نوشتن در پوشه پروژه (برای دیتابیس و تصاویر آپلودشده)
- پذیرندگی زرین‌پال برای پرداخت واقعی

## راه‌اندازی محلی

1. فایل‌های پروژه را در یک پوشه استخراج کنید.
2. در ترمینال وارد همان پوشه شوید و اجرا کنید:

   ```bash
   npm install
   ```

3. فایل `.env.example` را با نام `.env` کپی کنید.
4. برای اجرای محلی، `ZARINPAL_SANDBOX=true` را نگه دارید. شناسه پذیرندگی آزمایشی/مجاز را در `ZARINPAL_MERCHANT_ID` قرار دهید.
5. حساب مدیر اولیه را بسازید:

   ```bash
   npm run create-admin
   ```

   نام کاربری و رمز عبور در ترمینال پرسیده می‌شود. رمز عبور حداقل ۱۲ نویسه است و هنگام تایپ نمایش داده نمی‌شود. فقط یک حساب مدیر اولیه از این دستور ساخته می‌شود.

6. سرور را اجرا کنید:

   ```bash
   npm start
   ```

7. فروشگاه در `http://localhost:3000` و پنل در `http://localhost:3000/admin.html` در دسترس است.

**پنل مدیریت را با Live Server یا بازکردن مستقیم فایل HTML اجرا نکنید.** تمام صفحات باید از همین سرور باز شوند تا API و کوکی نشست کار کنند.

## قابلیت‌های پنل

- ورود و خروج مدیر با نشست تصادفی؛ توکن خام در دیتابیس ذخیره نمی‌شود.
- هش رمز عبور با scrypt و مقایسه زمان‌ثابت.
- افزودن، ویرایش، فعال/غیرفعال‌سازی و حذف نرم محصولات.
- بارگذاری تصویر JPG، PNG و WEBP تا ۴ مگابایت برای هر تصویر.
- مدیریت سفارش‌ها و تغییر وضعیت مرحله‌ای پس از پرداخت.
- دانلود نسخه پشتیبان سازگار SQLite از داخل پنل.
- نشست مدیر ۸ ساعت اعتبار دارد.

## دیتابیس و پشتیبان‌گیری

- مسیر پیش‌فرض دیتابیس `data/luna.sqlite` است.
- ساختار جدول‌ها و مهاجرت ستون‌های جدید هنگام شروع سرور اجرا می‌شود.
- موجودی هنگام ایجاد سفارش رزرو و از موجودی قابل فروش کم می‌شود. در صورت لغو/ناموفق بودن راه‌اندازی یا پرداخت، موجودی آزاد می‌شود.
- سفارش پرداخت‌نشده پس از ۳۰ دقیقه منقضی و موجودی آن آزاد می‌شود. اگر درگاه پس از انقضا پرداختی را گزارش کند، سفارش نیازمند بررسی دستی است.
- از دکمه «دانلود پشتیبان» در پنل برای دریافت فایل SQLite استفاده کنید. فایل پشتیبان را در محل امن و جدا از سرور نگه دارید.
- برای بازیابی، سرور را متوقف کنید، از دیتابیس فعلی یک کپی بگیرید و سپس فایل پشتیبان را به مسیر دیتابیس برگردانید.

## پرداخت زرین‌پال

تنظیمات `.env`:

```env
BASE_URL=https://your-domain.example
ZARINPAL_MERCHANT_ID=YOUR_MERCHANT_ID
ZARINPAL_SANDBOX=true
```

- `BASE_URL` باید نشانی عمومی قابل دسترس سرور باشد؛ برای محیط عملیاتی HTTPS الزامی است.
- مبلغ محصولات در دیتابیس به تومان ذخیره می‌شود و برای API زرین‌پال به ریال تبدیل می‌شود.
- سرور قیمت و موجودی را از دیتابیس می‌خواند؛ قیمت ارسالی مرورگر معتبر نیست.
- وضعیت پرداخت فقط پس از استعلام سمت سرور از زرین‌پال `paid` می‌شود.
- اطلاعات کارت بانکی در فروشگاه دریافت یا ذخیره نمی‌شود.
- بازپرداخت خودکار در این نسخه وجود ندارد؛ پرداخت‌های موفقی که باید مسترد شوند از پنل پذیرندگی و طبق فرایند صاحب پذیرندگی پیگیری شوند.
- قبل از فعال‌کردن حالت عملیاتی، درخواست و callback را با پذیرندگی آزمایشی و سپس حساب واقعی صاحب فروشگاه آزمایش کنید.

## تنظیمات امنیتی استقرار

در `.env` سرور عملیاتی:

```env
NODE_ENV=production
COOKIE_SECURE=true
TRUST_PROXY=1
BASE_URL=https://your-domain.example
ZARINPAL_SANDBOX=false
```

`TRUST_PROXY=1` فقط وقتی درست است که برنامه پشت یک reverse proxy مورد اعتماد باشد؛ مقدار صحیح را مطابق معماری هاست تنظیم کنید. HTTPS باید در هاست فعال باشد. فایل `.env`، دیتابیس و پوشه `data` را در وب‌سرور جداگانه منتشر نکنید.

## بررسی کد

```bash
npm run check
```

این فرمان فقط خطاهای نحوی JavaScript را بررسی می‌کند و جایگزین تست عملی سرور، مرورگر، درگاه و تنظیمات هاست نیست.

## ساختار اصلی

- `server.js`: API، سفارش، پرداخت، مدیریت و امنیت مسیرها
- `server/auth.js`: هش رمز و نشست مدیر
- `server/db.js`: ساخت و مهاجرت دیتابیس
- `server/payment.js`: اتصال زرین‌پال
- `admin.html` و `admin.js`: پنل مدیریت
- `script.js`: صفحه اصلی و سبد خرید
- `product.js`: صفحه جزئیات محصول
- `checkout.js`: تسویه‌حساب
- `assets/uploads/`: تصاویر بارگذاری‌شده مدیر
